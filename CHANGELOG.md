# Changelog

## v1.0.0 (2026-08-16)

First public release.

### Features
- Virtualized bytecode VM with per-build random instruction encoding
- Standard-grade string encryption (per-string independent keys)
- Multi-layer decryption chain with integrity checks
- Anti-dump and anti-debug runtime protection
- Three security tiers: lite / standard / max
- Bilingual CLI (English default, Chinese via `--lang zh`)
- Real-time colored progress output

### Notes
- Proprietary closed-source release
- Binaries distributed without source code
